# Beyond Gender: Exploring Language-Driven Biases in Fashion Image Generation

This repository contains the image dataset used in our study:  
**"Beyond Gender: Exploring Language-Driven Biases in Fashion Image Generation."**

The dataset includes AI-generated fashion images generated with **Spanish and Chinese** prompts, across **four experimental settings**:

- Spanish (with nationality)
- Spanish (without nationality)
- Chinese (with nationality)
- Chinese (without nationality)

Each setting contains:
- `neutral` prompts
- `male` prompts
- `female` prompts
